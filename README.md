# 衣物回收管理 PC 版

`衣物回收管理` 是一款面向 Windows 的本地桌面应用，适合衣物回收、分拣和二次流通场景中的日常记账、库存管理和订单确认。

当前仓库对应版本：`v1.0.6`

## 适用场景

- 需要在固定电脑上完成入库、出库、库存和订单管理
- 希望数据保存在本地，不依赖云端服务
- 需要把订单确认单导出后发送给客户留存

## 当前版本重点

### 交易录单更贴近一线使用

- 入库支持先填写，再进入确认单，只有点击“确认入库”后才会正式入账
- 出库支持按分类展开录单，更适合“一家只卖一种”的操作场景
- 入库和出库都支持在交易时切换计数单位，例如分类默认按公斤管理，但某次交易可以按斤录入
- 系统会自动换算交易数量，库存页仍统一按分类默认单位显示

### 订单链路更完整

- 订单名称统一为 `入库/出库_yyyy_MM_dd_HH_mm_客户名`
- 订单支持查看、编辑、删除和重新导出
- 修改订单时会保留原本交易单位，避免把 `20 斤` 错当成 `20 kg`
- 入库、出库确认单都支持导出 `PDF` 和 `PNG`

### 库存口径更清楚

- 同一分类支持保留多档入库价格
- 库存页会区分不同进价层，而不是只显示单一进价
- 支持盘点登记和手动调整
- 预计收入统一按“净利润”口径展示，并可查看计算公式

### PC 界面已进入统一改版

- 仪表盘、入库、出库、订单、库存、客户、预计收入、经营分析、设置都已切到同一套工作台式页面结构
- 页面重点更集中，说明文字更克制，减少视觉噪音

## 主要页面

### 仪表盘

- 查看今日入库金额、今日出库金额、库存成本、预计收入（净利润）
- 查看利润排行和当前经营概览

### 入库

- 先选择客户，再录入分类、数量、单价
- 支持多分类录入
- 支持交易单位切换
- 进入确认单后再次确认，才正式入库

### 出库

- 先浏览分类库存，再展开要出库的分类
- 支持选择客户、新增客户、填写数量和单价
- 支持交易单位切换
- 确认后生成出库确认单

### 订单中心

- 查看入库单、出库单详情
- 编辑订单、删除订单、导出订单确认单
- 支持 `PDF` 和 `PNG`

### 库存中心

- 查看库存数量、库存成本、进价分层、预计净利润
- 进行盘点登记和手动调整
- 查看待补货分类

### 客户中心

- 查看客户列表、最近订单和价格记忆
- 回看某个客户最近的交易习惯

### 设置

- 管理分类
- 做本地数据库备份与恢复
- 导入导出主数据和经营数据
- 查看诊断信息与日志目录

## 安装与数据

### 安装

- 建议从 GitHub Releases 获取最新安装包
- 安装器支持覆盖升级
- 默认安装目录为 `%LOCALAPPDATA%\\Programs\\ClothingRecycler`

### 数据位置

- 应用数据默认保存在 `%LOCALAPPDATA%\\ClothingRecycler`
- 卸载程序不会自动删除数据库、备份、导出文件和日志

## 常见问题

### 数据会不会上传到服务器？

不会。当前版本是纯本地桌面应用，核心数据保存在当前 Windows 用户目录。

### 订单填错了怎么办？

可以在“订单中心”里找到对应订单后直接编辑或删除，系统会同步回滚相关库存和派生数据。

### 能不能把确认单发给客户？

可以。确认单支持导出为 `PDF` 和 `PNG`，适合打印、归档或直接发给客户确认。

### 换电脑后还能继续用吗？

可以。先在旧电脑做备份，再把备份恢复到新电脑即可。
