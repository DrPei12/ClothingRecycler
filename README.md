# 衣物回收管理 PC 版

`衣物回收管理` 是一款面向 Windows 的本地桌面应用，适合衣物回收、分拣和二次流通场景中的日常记账、库存管理、订单确认和经营复盘。

当前仓库对应版本：`v1.0.7`

## v1.0.7 更新重点

### AI(Beta) 工作台

- 左侧栏新增 `AI(Beta)` 模块，可通过自然语言描述入库或出库需求。
- Agent 会自动判断业务路线，不再要求用户手动选择入库或出库模式。
- 当客户、分类、数量、单价等必要信息不完整时，Agent 会追问缺失字段。
- 信息完整后，Agent 会进入现有业务确认流：入库会弹出入库确认单，出库会进入对应创建流程。
- Agent 的关键步骤会展示在页面中，方便排查“理解、补全、工具选择、执行结果”的每一步。

### API 模型调用测试版

- 新增 `DeepSeek API (Beta)` Provider，可在本机设置中配置 `base_url`、`model` 和 API Key。
- API Key 仅保存在本机用户配置中，不写入仓库代码。
- 当前测试模型为 `deepseek-v4-flash`，用于把用户自然语言整理成结构化订单草稿。

### 语音输入与 ASR 模块

- 新增独立 ASR 模块，负责“音频输入 -> 语音识别 -> 文本后处理 -> Agent 输入”。
- ASR Provider 使用 Adapter 设计，后续可替换为本地 Whisper、云端 ASR、Windows 语音识别等实现。
- AI 页面支持音频文件识别和实时语音输入。
- 实时语音输入会把识别文本持续填入编辑框，用户可以先修正，再发送给 Agent。
- 实时语音状态会显示 Windows 识别器状态，避免 UI 假装转写但实际没有文本输出。

### 本地离线 AI 路线保留

- 保留 Hugging Face Ultravox + transformers 的本地模型路线，用于继续验证离线推理和语音模型方案。
- 保留 Ollama Provider 入口，后续可继续补齐本地 LLM 适配。

## 现有核心功能

### 交易录单

- 入库支持先填写，再进入确认单，只有点击“确认入库”后才会正式入账。
- 出库支持按分类展开录单，适合“一家只卖一种”的高频操作场景。
- 入库和出库都支持在交易时切换计数单位，例如分类默认按公斤管理，但某次交易可以按斤录入。
- 系统会自动换算交易数量，库存页仍统一按分类默认单位显示。

### 订单链路

- 订单名称统一为 `入库/出库_yyyy_MM_dd_HH_mm_客户名`。
- 订单支持查看、编辑、删除和重新导出。
- 修改订单时会保留原本交易单位，避免把 `20 斤` 错当成 `20 kg`。
- 入库、出库确认单都支持导出 `PDF` 和 `PNG`。

### 库存与经营分析

- 同一分类支持保留多档入库价格。
- 库存页会区分不同进价层，而不是只显示单一进价。
- 支持盘点登记和手动调整。
- 预计收入统一按“净利润”口径展示，并可查看计算公式。
- 仪表盘、经营分析、预计收入页面用于查看当前经营概览和利润排行。

## 主要页面

- `仪表盘`：查看今日入库金额、今日出库金额、库存成本、预计收入和经营概览。
- `入库`：选择客户，录入分类、数量、单价，进入确认单后正式入库。
- `出库`：浏览分类库存，展开分类录单，确认后生成出库记录。
- `库存`：查看库存数量、库存成本、进价分层、预计净利润和盘点记录。
- `订单`：查看入库单、出库单详情，编辑、删除、导出订单确认单。
- `客户`：查看客户列表、最近订单和价格记忆。
- `AI(Beta)`：通过文本、音频文件或实时语音把自然语言转为业务订单草稿。
- `设置`：管理分类、本地备份恢复、导入导出、AI Provider 和诊断信息。

## AI 功能规划

### 短期计划

- 完善 DeepSeek API 模式下的入库、出库结构化输出稳定性。
- 优化实时语音识别体验，包括更可靠的麦克风检测、流式转写和错误提示。
- 补齐 AI 对多行订单、模糊客户、模糊分类和单位换算的追问策略。
- 让 Agent 对每一步工具调用给出更清楚的可视化解释。

### 中期计划

- 将客户端常用操作逐步工具化，例如创建订单、新建客户、查询库存、打开确认单、导出订单。
- 建立更完整的 Workflow Agent：先理解用户意图，再检查信息完整性，最后调用业务工具执行。
- 增加短期会话记忆，让用户补充一句话时能接上上一轮未完成订单。
- 增加长期结构化记忆，把客户偏好、常用分类、常见价格和历史订单摘要写入本地数据库。

### 长期计划

- 支持上传操作手册、安全协议、业务规则等文档，让 AI 能回答操作流程和注意事项。
- 支持库存分析、订单总结、售卖趋势、客户交易习惯和经营建议。
- PC 端优先支持本地模型以提升响应速度和离线能力。
- Android 端优先支持 API 模型以节省空间并降低部署复杂度。
- 统一 PC 与 Android 的 Agent 协议，让两端共享同一套业务理解和工具调用规范。

## 安装与数据

### 安装

- 建议从 GitHub Releases 获取最新安装包。
- 安装器支持覆盖升级。
- 默认安装目录为 `%LOCALAPPDATA%\Programs\ClothingRecycler`。

### 数据位置

- 应用数据默认保存在 `%LOCALAPPDATA%\ClothingRecycler`。
- 卸载程序不会自动删除数据库、备份、导出文件和日志。

## 常见问题

### 数据会不会上传到服务器？

核心业务数据保存在本机。只有当你启用 API Provider 时，发给 AI 的文本指令会发送给你配置的模型服务；API Key 保存在本机配置中。

### AI 会直接改库存吗？

不会跳过确认。AI 会生成可复核的订单草稿，并进入现有确认流程；最终是否确认入库或出库仍由用户决定。

### 语音输入为什么可能没有文字？

实时语音依赖 Windows 语音识别、麦克风权限、默认输入设备和语言包。如果页面显示会话运行但没有文本输出，通常说明 Windows 识别器没有返回候选文本，需要检查系统语音设置。

### 订单填错了怎么办？

可以在“订单中心”里找到对应订单后直接编辑或删除，系统会同步回滚相关库存和派生数据。

### 能不能把确认单发给客户？

可以。确认单支持导出为 `PDF` 和 `PNG`，适合打印、归档或直接发给客户确认。
