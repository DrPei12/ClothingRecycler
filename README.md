# ClothingRecycler Android

这是 `衣物回收管理` 的 Android 版本源码分支。

当前版本：
- `versionName`: `1.0.0`
- `versionCode`: `1`

技术栈：
- `Kotlin`
- `Jetpack Compose`
- `Hilt`
- `Room`

主要目录：
- `app/src/main`：应用主源码与资源
- `app/src/test`：单元测试
- `gradle`：Gradle 配置

说明：
- 这个分支只保留 Android 正式项目源码
- 不包含开发报告、设计草稿和本机构建缓存
- GitHub release 会单独挂载当前最新 APK
