## 这是什么

这是一个装在 Windows 电脑上的本地软件，用来管理：
- 衣物入库
- 衣物出库
- 当前库存
- 客户信息
- 订单记录
- 经营统计

它不是网页，也不是小程序。安装后像普通电脑软件一样打开就能用。

## 怎么安装

找到这个安装文件：

`D:\Desktop\ClothingRecycler_PC\artifacts\release\ClothingRecycler_PC_Install_v1.0.0.exe`

安装步骤：
1. 双击打开它
2. 如果 Windows 提示是否允许，点“允许”或“继续”
3. 安装器会先让你选安装位置
4. 默认会给一个推荐路径，你可以直接用，也可以改到别的盘
5. 等安装完成
6. 安装后桌面会出现一个 `衣物回收管理` 图标
7. 双击桌面图标就能打开

## 第一次打开，先做什么

建议按这个顺序来：

### 第一步：先建分类

进入 `设置`，把你常用的分类先建好。

比如：
- 夏装
- 冬装
- 鞋子
- 包

每个分类可以设置单位，比如：
- 公斤
- 斤
- 件

### 第二步：录入第一批入库

进入 `入库` 页面，填写：
- 分类
- 数量
- 单价
- 客户

保存后，系统会自动：
- 增加库存
- 生成订单记录
- 记住这个客户最近的价格

### 第三步：有卖出或流出时录出库

进入 `出库` 页面，填写：
- 分类
- 数量
- 单价
- 客户

系统会自动检查库存够不够，够的话才会出库。

### 第四步：平时看库存和订单

你可以去：
- `库存` 看还剩多少货
- `订单` 看每一笔记录
- `客户` 看客户和最近交易
- `经营分析` 看整体经营情况

## 如果你只记住三件事

### 1. 分类要先建好

没分类就没法正常录入库和出库。

### 2. 订单录错了，可以改

如果入错或出错，不用慌，到 `订单中心` 找到那一笔，直接编辑或删除就行。

### 3. 记得备份

进入 `设置`，定期点一下备份。尤其是在：
- 大批量改数据前
- 换电脑前
- 升级新版本前

## 数据会不会丢

正常不会，这个软件现在是 `纯本地` 的：
- 不依赖服务器
- 不要求联网
- 数据存在你自己的电脑里

而且：
- 卸载软件不会自动删掉你的账本
- 可以自己做备份
- 可以从备份恢复

数据主要在这里：

`%LOCALAPPDATA%\ClothingRecycler`

## 常见问题

### 安装后桌面没看到图标怎么办？

去开始菜单里找 `衣物回收管理`。如果能打开，说明已经装好了。

### 打不开怎么办？

先重启一次电脑再试。如果还是不行：
- 看看是否被安全软件拦截
- 看日志目录 `%LOCALAPPDATA%\ClothingRecycler\logs`

### 卸载会把数据一起删掉吗？

不会。卸载只删程序，不删你的数据库和备份。

### 可以在另一台电脑继续用吗？

可以，但要把数据一起带过去。最稳妥的方法是：
1. 在旧电脑先做一次备份
2. 把备份文件复制到新电脑
3. 在新电脑恢复备份

### 现在能和安卓同步吗？

还不行。当前版本先把 Windows 本地版做稳，后续再考虑互通。

## 最后给你的建议

如果你平时不想管太多技术问题，就记住这 4 件事：
1. 先建分类再记账
2. 入库和出库都尽量当天录
3. 每周备份一次
4. 换电脑前先备份

这样基本就能稳定用了。
