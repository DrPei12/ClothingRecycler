# 衣物回收管理 PC 版，快速上手

这份说明是给最终使用者准备的，尽量只讲怎么装、怎么用。

## 这是什么

这是一个装在 Windows 电脑上的本地软件，用来管理：

- 衣物入库
- 衣物出库
- 当前库存
- 客户信息
- 订单记录

## 先看界面

![主界面](./docs/screenshots/main-window.png)

你平时最常用的页面，一般就是：

- `入库`
- `出库`
- `库存`
- `订单`
- `设置`

## 怎么安装

- 从 GitHub Releases 下载最新安装包
- 双击安装包后，按提示选择安装目录
- 安装完成后，可从桌面或开始菜单打开 `衣物回收管理`

## 第一次使用，建议这样开始

### 第一步：先建分类

进入 `设置`，先把常用分类建好，比如夏装、冬装、鞋子、包等。

### 第二步：录入第一批入库

进入 `入库` 页面后：

- 先选择已有客户或新增客户
- 再填写本次入库的分类、数量和单价
- 确认后系统会自动生成订单和库存记录

### 第三步：需要卖出时录出库

进入 `出库` 页面后：

- 先看每个分类当前库存和计量方式
- 点击要出库的类别展开编辑区
- 选择客户或新增客户，再填写数量和单价
- 确认后系统会自动生成出库订单

### 第四步：去订单页导出确认单

在 `订单` 页面选中一笔订单后，可以直接导出：

- `PDF`
- `PNG`

这样就能发给客户做确认。

## 如果你只记住三件事

### 1. 分类要先建好

没分类就没法规范地录入库和出库。

### 2. 订单录错了可以改

去 `订单中心` 找到那一笔，直接编辑或删除即可。

### 3. 记得备份

进入 `设置`，定期做一次本地备份。换电脑前也建议先备份。

## 数据会不会丢

正常不会。

- 这个软件不依赖服务器
- 数据存在你自己的电脑里
- 卸载软件不会自动删掉你的账本

数据默认在这里：

`%LOCALAPPDATA%\\ClothingRecycler`

## 常见问题

### 安装后桌面没看到图标怎么办？

去开始菜单里找 `衣物回收管理`。如果能打开，说明已经安装成功。

### 打不开怎么办？

先重启电脑再试；如果还是不行，可以查看日志目录 `%LOCALAPPDATA%\\ClothingRecycler\\logs`。

### 卸载会把数据一起删掉吗？

不会。卸载只删除程序，不删除数据库、备份和导出文件。

### 可以在另一台电脑继续用吗？

可以，先在旧电脑做好备份，再把备份恢复到新电脑即可。
